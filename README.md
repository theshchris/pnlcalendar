## English

PnL Calendar is a free, ad-free performance calendar for investors. It presents
daily, monthly, and yearly profit and loss in a clear calendar while keeping
financial data on your device.

The current version connects to Interactive Brokers and can be used to review
U.S. and global stocks, ETFs, options, futures, and other investments reported
by the account. Results are consolidated in the account's base currency.

### Features

- Daily, monthly, and multi-year performance calendars
- Net P&L, time-weighted return, and win rate
- Display P&L, return, or both together
- Optional realized P&L, dividends, interest, commissions, and other details
- Optional automatic sync at launch and manual sync
- Native iPhone and iPad layouts with four languages and light/dark themes

### Connecting Interactive Brokers

Synchronization requires your own Activity Flex Query ID and Flex Token. Create
an XML Activity Flex Query in IBKR Client Portal, include **Change in NAV** and
the fields you want to display, then enter the Query ID and Token in the app.

The connection is read-only. PnL Calendar cannot place trades, manage funds, or
change account settings.

### Privacy

The app connects directly from your device to Interactive Brokers over HTTPS.
Credentials are stored in the iOS Keychain, and downloaded reports remain in
the app's private storage. There is no developer-operated backend, advertising,
analytics SDK, or cross-app tracking.

Read the complete [Privacy Policy](https://github.com/theshchris/pnlcalendar/blob/main/PRIVACY.md).
